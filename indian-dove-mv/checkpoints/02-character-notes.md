# 检查点 2：角色造型审核

请优先查看 `02-cast-sheet.png` 与 `02-expressions.png`。当前需要确认主角外形、配角辨识度和表情方向；未进入背景与剧情镜头制作。

- 老斑鸠：灰褐身体、粉灰胸口、短腿、秃斑、三根头毛、垂眼皮、红黄羽饰、木珠项链。
- 9 表情：发呆、饿昏、秀逗、伤心、生气、心动、学人说话、困惑、睡觉。
- 5 动作：踱步、打瞌睡、扑翅、躺倒、跳舞。
- 16 类配角：母斑鸠、乌鸦、响尾蛇、灰狼、秃鹰、野牛（2 头）、蜥蜴、害羞仙人掌、像猫的狗、海鸥、泥鳅、牛仔、决斗对手、巫师、酋长、骷髅头。
- 四个人物共享比例辅助组件，但各有独立角色入口、衣着、道具与头饰。
- 角色 SVG 坐标系为 300×340；父场景负责世界坐标、视差、镜头、走位与全局质感。
- CharacterProps 提供 frame、expression、pose、blink、variant。主角实现全套表情/姿态；配角仅使用各自适用属性，不把接口存在等同于所有剧情动作已实现。
- 一拍二只应用角色姿态；测试片进度线仍每帧平滑更新。
- 动作测试无声，不用于音画同步验收。

## 复现

在工程目录运行 `npm run cast`、`npm run expressions`、`npm run poses`、`npm run character-preview`。
当前主机需在命令前添加 `NODE_OPTIONS=--require=./tools/loopback.cjs`，详见工程 README。
